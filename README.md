## 🔍 কোন ফাইলে কী কী কাজ হচ্ছে? (Technical Module Breakdown)

### ১. `render.yaml`
- **Render Web Service Blueprint:** Render-এ রিপোজিটরি কানেক্ট করলে এটি স্বয়ংক্রিয়ভাবে পরিবেশ চিহ্নিত করে।
- **স্বয়ংক্রিয়মেটিক মুছে দেয়।

### ৪. `app.py` (কোর ব্যাকএন্ড ও গেটওয়ে ইঞ্জিন)
- **পাবলিক শর্টনার API:** হোমপেজ থেকে যে কেউ বড় URL দিলে তাৎক্ষণিক ৬ ডিজিটের ইউনিক শর্ট কোড তৈরি করে।
- **মাল্টি-স্টেপ ট্রাফিক কন্ট্রোলার (`/s/{code}`):** ইউজার ঢুকলে স্টেপ বাই স্টেপ ভ্যালিডেশন টোকেন ইস্যু করে রিডাইরেক্ট করে। ট সেটিংস:** পাইথন ৩.১১ নির্ধারণ, প্যাকেজ ইনস্টলেশন, ইউভিকর্ন (`Uvicorn`) ওয়ার্কার কমান্ড এবং স্বাস্থ্য পরীক্ষা (`/health`) পরিচালনা করে।

### ২. `requirements.txt`
- **Fastোকেন ছাড়া কেউ সরাসরি ফাইনাল পেজে স্কিপ করতে পারে না।
- **স্মার্ট ডিরেক্ট লিংকAPI ও Uvicorn:** উচ্চ পারফরম্যান্সের অ্যাসিনক্রোনাস ওয়েব সার্ভার।
- **Motor ও রোটেটর:** অ্যাডমিন যতগুলো Monetag বা Adsterra লিংক দেবে, সেগুলোর ওজন (Weight) অনুযায়ী প্রতি স্টে PyMongo:** MongoDB Atlas ক্লাউডের সাথে নন-ব্লকিং ডাটাবেজ কানেকশন।
- **pyTelegramপে ইউজারকে আলাদা আলাদা অ্যাড দেখায়।
- **সুপার অ্যাডমিন API (`/admin`):**
  - লাইভ অ্যানালিটিক্স (মোট ক্লিক, আজকের ক্লিক, গতকালের ক্লিক)।
  - স্টেপ বাড়ানো/কBotAPI (telebot):** টেলিগ্রাম বটের ব্যাকগ্রাউন্ড মাল্টি-থ্রেডিং মেসেজ প্রসেসিং।
- **itsdangerousমানো এবং টাইমার পরিবর্তন করা।
  - চ্যানেল ইউজারনেম/আইডি এবং অটো-ডিলিট মিনিট সেভ করা।

### ৫. `templates/index.html` (পাবলিক ইন্টারফেস)
-:** প্রতিটি রিডাইরেক্ট স্টেপে সিকিউর এইচএমএসি (HMAC) সাইনড টোক **Home View:** ডার্ক নিয়ন প্রিমিয়াম শর্টনার ফর্ম।
- **Step View:** রেন তৈরি ও বাইপাস রোধক ক্রিপ্টোগ্রাফি।

### ৩. `bot.py` (িয়েলটাইম কাউন্টডাউন টাইমার (৭ সেকেন্ড/১০ সেকেন্ড)। টাইমার শেষ হলে বাটন সচল হয় এবং ক্লিক করলে ডিরেক্ট অ্যাড ওপেন হয়ে পরের স্টেপে নিয়ে যায়।
- **Final View:** টেলিগ্রাম ফাইটেলিগ্রাম কোর ইঞ্জিন)
- **ইনকামিং মিডিয়া হ্যান্ডলার:** ব্যবহারকারী বটে কোনো ডকুমেন্ট, ফুল এইচডি ভিডিও, অডিও বা ফটো দিলে টেলিগ্রামের নিজস্ব ক্লাউড থেকে `file_id` ধরে ডাটাবেজে সংরক্ষণ করে এবংলের ক্ষেত্রে সরাসরি বটের ডিপলিংক ওপেন করার আকর্ষণীয় বাটন প্রদর্শন করে।

### ৬. `templates/admin.html শর্ট লিংক তৈরি করে।
- **অ্যালবাম ও ব্যাচ ডিটেকশন (`ALBUM_CACHE`):** ইউ` (অ্যাডমিন প্যানেল)
- **লগইন ও ড্যাশবোর্ড:** পাসওয়ার্ড প্রটেক্টেড।

## 🚀 ক্লাউডে ডিপ্লয় করার নিয়মাবলী (Step-by-Step Deploymentটেটর (`resolve_weighted_direct_link`):**
  - অ্যাডমিন যতগুলো Monetag বা Adsterra ড Guide)

1. গিটহাবে একটি নতুন রিপোজিটরি তৈরি করে উপরের ফাইলগুলো হুবহু পুশ করুন।
2িরেক্ট লিংক যোগ করবে, সিস্টেম ওয়েট (Weight) অনুযায়ী প্রতি স্টেপে ভিন্ন ভিন্ন বিজ্ঞাপন ওপেন করবে।
- **ক্লিক অ্যানালিটিক্স:** মোট ক্লিক, আজকের ক্লিক, গতকালের ক্লিক এবং কোন ডিরেক্ট লিংকে কত ক্লিক. **Render.com**-এ লগইন করে **New Web Service** সিলেক্ট করুন এবং আপনার রিপোজিটরিটি কানেক্ট করুন।
3. সেটিংস দিন:
   - **Runtime:** `Python 3`
   - **Build Command:** `pip install --upgrade pip && pip install -r requirements.txt`
   - **Start Command:** `uvicorn app:app পড়েছে তা নিখুঁতভাবে গণনা করে।
- **এডমিন কন্ট্রোল API:** চ্যানেল আইডি, পাবলিক শর্টনার সুইচ এবং স্টেপ ম্যানেজমেন্ট পরিচালনা করে।

### ৫. `templates/index.html` (ক্লায়েন্ট ফ্রন্টএন্ড) --host 0.0.0.0 --port $PORT --workers 1`
4. **Environment** ট্যাবে উপরের টেবিলের ৬টি ভ্যারিয়েবল বসিয়ে **Deploy** দিন।
5. সার্ভিস লাইভ হলে প্রাপ্ত ডোমেইনটি `BASE_URL`-এ আপডেট করে দিন।
